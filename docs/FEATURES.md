# Scope نهایی نسخه 1.0

## هسته محصول
1. وام بانکی، خودرو، مسکن، کالا، بدهی شخصی، بیمه، صندوق و سایر
2. جدول اقساط خودکار با تقویم جلالی
3. پرداخت کامل/جزئی
4. ویرایش مبلغ و تاریخ هر قسط
5. وضعیت pending / partial / paid / overdue
6. یادآوری‌های قابل تنظیم

## وجه تمایز تحلیلی
- فشار پرداخت ۶ ماه آینده
- مجموع تعهد این ماه و ماه بعد
- میانگین تعهد ماهانه
- سنگین‌ترین ماه پیش‌رو
- مبلغ/تعداد معوق
- مانده کل بدهی
- درصد پیشرفت هر وام
- تاریخ تقریبی بدون بدهی
- Insight متنی بر مبنای داده قطعی، بدون AI/API
- تشخیص تجمع چند قسط در سه روز آینده

## اعتماد و انتشار
- Offline-first
- SQLite
- Backup/Restore
- CSV / PDF
- Biometric lock
- Light/Dark/System
- RTL
- API 36
- بدون نیاز به دسترسی بانکی، پیامک یا مخاطبین
