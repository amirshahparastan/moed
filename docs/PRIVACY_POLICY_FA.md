# حریم خصوصی موعد — نسخه ۱.۰

موعد محصولی از PULSE است و با تمرکز بر Local-first طراحی شده است.

- اطلاعات وام‌ها، اقساط و پرداخت‌ها به‌صورت پیش‌فرض روی دستگاه کاربر نگهداری می‌شود.
- موعد برای عملکرد اصلی خود نام کاربری یا رمز حساب بانکی درخواست نمی‌کند.
- مجوز اعلان برای یادآوری سررسیدها استفاده می‌شود.
- احراز هویت بیومتریک توسط سیستم‌عامل انجام می‌شود و داده خام اثرانگشت/چهره در برنامه ذخیره نمی‌شود.
- بکاپ، PDF و CSV فقط با اقدام کاربر ایجاد یا اشتراک‌گذاری می‌شوند.
- نسخه ۱.۰ برای هسته مدیریت اقساط به سرویس تبلیغاتی اجباری متصل نیست.
