# مرور محصول موعد — نسخه ۱.۰

## جایگاه محصول
موعد یک «دفترچه قسط» ساده نیست؛ هدف نسخه ۱ تبدیل شدن به دستیار مدیریت اقساط فارسی با سه ستون اصلی است:

1. ثبت و پیگیری دقیق تعهدها و پرداخت‌ها
2. یادآوری و تقویم شمسی
3. تحلیل فشار مالی و برنامه‌ریزی برای زودتر تمام کردن بدهی

## قابلیت‌های نسخه ۱
- رابط فارسی و RTL
- Vazirmatn در کل UI
- Light / Dark / System
- ثبت وام، خرید اقساطی، مسکن، خودرو و کالا
- ساخت خودکار جدول اقساط ماهانه/هفتگی
- ویرایش مبلغ و تاریخ هر قسط
- پرداخت کامل و جزئی
- پرداخت زودتر چند قسط با یک مبلغ
- تقویم شمسی با راهنمای وضعیت پرداخت‌شده/در انتظار/معوق
- Reminder قبل سررسید و پیگیری معوق
- افق ۳۰ روز آینده
- گزارش ۶/۹/۱۲ ماهه
- مانده بدهی، مبلغ معوق، میانگین پرداخت و تاریخ تقریبی پایان بدهی
- نقطه عطف درصد پرداخت کل
- سناریوی «اگر ماهی بیشتر پرداخت کنم»
- PDF هر وام و CSV کل اقساط
- بکاپ و بازیابی
- قفل بیومتریک در Android
- Local-first و بدون نیاز به اتصال حساب بانکی
- صفحات درباره برنامه، حریم خصوصی و شرایط استفاده
- بازخورد مستقیم به PULSE

## چرا این قابلیت‌ها برای V1 انتخاب شدند
نسخه ۱ باید سریع و قابل اعتماد بماند. قابلیت‌هایی مثل OCR قرارداد/جدول اقساط، Cloud Sync، اتصال بانکی، Home Widget و همگام‌سازی خانوادگی جذاب‌اند، اما برای انتشار اولیه ریسک فنی و حریم خصوصی بیشتری دارند و بهتر است بعد از تثبیت هسته اضافه شوند.

## نقشه راه پیشنهادی بعد از انتشار
- OCR از عکس جدول اقساط و ساخت خودکار سررسیدها
- ویجت Android برای قسط بعدی
- Quick Action از آیکن برنامه
- Cloud Sync اختیاری رمزگذاری‌شده
- فضای مشترک زوج/خانواده
- رسید و ضمیمه برای هر پرداخت
- ماشین‌حساب سود/کارمزد و مقایسه شرایط وام
- Timeline کامل فعالیت‌ها و پرداخت‌ها
- Export/Import پیشرفته‌تر
- اعلان‌های Actionable برای ثبت پرداخت از Notification
